# wallet-ledger

Wallet and ledger service. Owns the append-only (event-sourced) money ledger
for deposits, wagers, grades, payouts, and bonus credits — all balances must
be reconstructable and auditable.

See the [root README](../../README.md#backend-services) for how this fits
into the overall architecture. Not yet implemented — depends on Phase 0
(compliance foundation) and a gaming-capable payment processor integration.
